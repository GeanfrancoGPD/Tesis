# Documentación de la API

## URL base

```text
/api
```

La API utiliza sesiones mediante cookies. Las peticiones protegidas deben
enviar la cookie `connect.sid`.

## Módulos

### Usuarios

Incluye registro, inicio y cierre de sesión, validación de sesión,
actualización y eliminación de cuentas.

[Consultar documentación del módulo de usuarios](./usuarios.md)
